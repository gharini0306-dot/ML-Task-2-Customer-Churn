# Customer Churn Prediction

## Project Overview

This project focuses on framing a machine learning problem for customer
churn prediction and documenting responsible data practices.

## Objective

The objective is to predict whether a customer is likely to churn based
on available customer information.

## Dataset

The dataset contains customer information such as:

- Tenure
- Support tickets
- Monthly spending
- Last login days
- Plan type
- Churn status

## Machine Learning Model

A Logistic Regression model was developed as a baseline model.

## Evaluation Metrics

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Responsible AI

The project includes:

- ML Problem Framing
- Responsible Data Card
- Risk Register
- Human Review
- Monitoring
- Rollback Conditions

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
- VS Code
